# HexSoftware

## Web Development Mini Projects (HTML, CSS & JavaScript)

This repository contains a collection of beginner-friendly web development projects built using **HTML, CSS, and JavaScript**. These projects focus on strengthening core front-end skills, improving UI structuring, and understanding basic client-side functionality.

### Projects Included

### **Personal Portfolio Website**

A responsive personal portfolio built using **HTML and CSS**.

* Sections include **Bio, Skills, Experience, and Contact Information**
* Clean layout and basic styling
* Designed to showcase personal and professional details

### **To-Do List Web App**

A simple and interactive **To-Do List application** using **HTML, CSS, and JavaScript**.

* Add, delete, and mark tasks as completed
* Uses **Local Storage** to save tasks in the browser
* Helps understand DOM manipulation and browser storage

### **Resume Website (HTML Only)**

A minimal **resume website created using only HTML**.

* Header with name, title, and profile image
* About Me section highlighting skills and experience
* Skills section covering technical and soft skills
* Focuses on semantic HTML and content structure

### Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla)

### Purpose

 A collection of beginner-friendly web projects built using HTML, CSS, and JavaScript.
Includes a personal portfolio, to-do list app with local storage, and a resume website for practicing core web development skills.
